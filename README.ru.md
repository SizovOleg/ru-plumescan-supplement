# RU-PlumeScan — дополнительные материалы

**Каталог метановых аномалий Западно-Сибирской равнины по данным TROPOMI/Sentinel-5P, 2019–2025.**

[English version](README.md)

Этот репозиторий содержит данные, программный код и описание методики, сопровождающие статью. Он самодостаточен: каталог событий доступен в машиночитаемом виде, все параметры обработки задокументированы, вычисления воспроизводимы.

## Существенные оговорки

Эти ограничения важны для корректного прочтения результатов.

**1. Независимые каталоги — не эталонная истина.** Schuit et al. (2023) и UNEP IMEO MARS нацелены на крупные источники газовых месторождений и систематически не покрывают факельное сжигание. Расхождение с ними означает различие в охвате, а не ошибку детекции. Из 62 событий без совпадений 44 отнесены к факелам.

**2. Порог z ≥ 3.0 — рабочий, установленный эмпирически.** Он не является уровнем значимости и не подразумевает вероятностной интерпретации.

**3. Оценки массового расхода не приводятся.** Каталог содержит только характеристики аномалии (z-оценка, превышение в ppb, площадь). Расчётный предел обнаружения ~3–5 т/ч получен теоретически и не подтверждён измерениями.

**4. Каталог собран двумя версиями алгоритма** — 83 записи версии 2.3.2 и 39 версии 3.1.4. Различие затрагивает только правила отнесения к артефактам, детекция идентична.

**5. Зимние месяцы отсутствуют.** При низком солнце и снежном покрове восстановление XCH₄ в высоких широтах недоступно, поэтому каталог охватывает март–октябрь.

**6. Известный дефект одной записи.** У события `CH4-WSP-017` (01.07.2020) поля `max_z` и `mean_z` равны нулю — это сентинель «статистика не вычислена», а не измеренное значение; в той же записи расходятся счётчики пикселей (`count` = 18, `n_pixels` = 13). Дефект возник на этапе детекции и прослеживается до промежуточного ассета. Запись сохранена в каталоге ради согласованности с опубликованными числами; при расчёте статистик по z-оценке её следует исключать.

**7. Происхождение границы области интереса.** Контур Западно-Сибирской равнины загружен как готовый векторный слой; сведения о том, по какому картографическому источнику он оцифрован, в проектных материалах не сохранились. Это ограничение прослеживаемости, не влияющее на воспроизводимость: сам слой публикуется вместе с каталогом.
